# Selective Walls

Стены, которые полностью отсутствуют у выбранных игроков: они их не видят и проходят сквозь них.
Модуль для **Foundry VTT v14**, работает с любой игровой системой.

Список игроков задаётся на самой стене. Обработка происходит локально на клиенте каждого игрока,
поэтому документы сцены не меняются, а настройка автоматически синхронизируется между клиентами.

## Возможности

- Для выбранного игрока стена **полностью исчезает**: она не рисуется, иконка и меши двери скрыты.
- Стену нельзя выделить или кликнуть по ней — для этого игрока она недоступна для взаимодействия.
- Зрение, свет, звук и перемещение проходят сквозь стену: персонаж свободно видит, слышит и ходит
  через неё.
- Скрытие действует на выбранного пользователя на любом уровне сцены, независимо от того, каким
  токеном он управляет.
- Мастер всегда видит все стены и может их настраивать.
- Списки персонажей и отдельных токенов из прежних версий модуля продолжают работать.
- Необязательный отладочный вывод в консоль.

## Установка

1. Скопируйте папку `selective-walls` в каталог модулей Foundry: `Data/modules/selective-walls`.
2. Включите модуль в настройках мира (**Manage Modules**).
3. Обновите сцену клавишей **F5**.

Зависимостей нет.

## Как пользоваться

1. Включите модуль в настройках мира.
2. Выделите нужную стену и откройте её настройки (шестерёнка или правый клик по стене).
3. Внизу окна появится секция **«Скрыта для этих игроков»** с выпадающим списком пользователей мира
   (кроме Мастера). Выберите имена — они превратятся в «чипы», которые можно удалить.
4. Изменения сохраняются сразу, отдельная кнопка не нужна. Закройте окно как обычно.
5. Игрок увидит результат немедленно: стена исчезнет, а проход сквозь неё станет свободным.

| Действие | Результат |
| --- | --- |
| Выбрать игрока в списке стены | Стена исчезает на клиенте этого игрока |
| Удалить «чип» игрока | Стена снова появляется у этого игрока |
| Открыть стену под Мастером | Список доступен для просмотра и изменения |
| Открыть стену без прав | Список виден, но недоступен для изменения |

## Кого касается скрытие

- Стена скрывается на клиенте **выбранного пользователя** — независимо от его токена и уровня
  сцены.
- Дополнительно поддерживаются прежние списки: стена скрывается у игроков, которые владеют или
  наблюдают отмеченного персонажа либо управляют его токеном.
- Мастер (`GM`) никогда не прячет стены — иначе он потерял бы возможность их настраивать.
- Игрок, для которого стена скрыта, не может её выделить и открыть настройки, поэтому списки ведёт
  Мастер или пользователь с правами на стену.

## Настройки

| Настройка | По умолчанию | Описание |
| --- | --- | --- |
| Отладочный вывод | выключено | Пишет в консоль число скрытых стен и факты пересчёта полигонов зрения |

Настройка хранится отдельно для каждого клиента.

## Совместимость

- Foundry VTT **14** (проверено на сборке 14.369).
- Для более старых версий модуль не адаптирован.
- Работает на текущем уровне сцены; при переключении уровня состояние пересчитывается заново, а
  списки сохраняются в документах стен.
- Стена остаётся стеной для всех остальных: Мастер и игроки вне списка видят её, и она блокирует
  их как обычно.
- Скрытие не прячет содержимое за стеной само по себе: обычные освещение и туман войны продолжают
  работать штатно.
